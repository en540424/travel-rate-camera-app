# 保存写真の変更シート ・ spec

- **フォルダ**：`photo-action-sheet/`
- **画面名**：保存する写真（アクションシート）
- **状態**：保存写真の変更 / 商品写真を撮る
- **表示形態**：結果パネル上のボトムシート（背面 dim）
- **元デザイン**：`メイン画面 最終案 v4`

## 数値仕様

| 項目 | 値 |
|---|---|
| 背面 dim | `rgba(16,33,31,0.42)`（結果パネルを `opacity:0.4` で透かす） |
| シート外 padding | 12 |
| シート本体 | bg `#fff`・radius **20**・`box-shadow:0 -6px 24px rgba(16,33,31,0.2)` |
| ヘッダー | 中央・「保存する写真」14/700 ＋「値札と商品写真は別でもOK」11.5/500・下に区切り線 |
| **商品写真を撮る（最上部・強調）** | bg `#F4FBF9`・アイコン枠34（teal塗り白）＋「商品写真を撮る」14.5/700 ＋ 補足「履歴で見返しやすい写真に」 |
| 写真ライブラリから選ぶ | アイコン枠30 `#F5F7F6`＋ラベル14.5/600 |
| OCR写真を使う | 同上 ＋ 右にチェック（teal・現在選択中の意） |
| 写真を削除 | アイコン枠 `#FBEDEA`・文字 `#D9614E`（破壊的） |
| 行区切り | 1px `#F0F3F1`（左右18マージン） |
| キャンセル | 別カード・radius16・50高・「キャンセル」15/600 |

## 注意
- **「商品写真を撮る」を最上部・teal背景で強調**（「変更」より一段強い導線）。
- OCR写真と保存写真を明確に分離（値札と商品は別でOK）。

## RN移植メモ（差分）
- `@gorhom/bottom-sheet` か `Modal`＋下スライド。背面 dim は `Pressable`（onClose）。
- アクションは `PhotoAction` 型（shootProduct / pickLibrary / useOcrPhoto / remove）。`displayPhotoUri` を更新。
- 削除は破壊的色（`alert #D9614E`）。確認は別途。
