## 注意
- 保存先・残予算更新・履歴/続けて撮影を提示。**「続けて撮影」で価格OCRへ最短復帰**（`phase='capture' / mode='ocr'`）。
- 見出し・バッジ色は `bucket` に追従（候補=amber / 購入済み=teal）。

## RN移植メモ（差分）
- `phase='saved'` の表示。`SavedConfirm` コンポーネント。
- 「続けて撮影」→ state を `capture/ocr` にリセット（保存はしない）。
- 完了アイコンは出現アニメ（`scale` spring）を付けると気持ちよい（任意）。
