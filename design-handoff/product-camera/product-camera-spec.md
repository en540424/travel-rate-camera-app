# 商品写真モード ・ spec

- **フォルダ**：`product-camera/`
- **画面名**：商品写真モード（補助）
- **状態**：撮影前・補助モード
- **下タブ active**：カメラ
- **元デザイン**：`メイン画面 最終案 v4`
- **route**：`app/(tabs)/index.tsx`（mode='product'）

`main/`（価格OCR）との **差分のみ** 記載。共通の枠・余白は `main-spec.md` と同一。

## 差分

| 項目 | main（OCR） | product（商品写真） |
|---|---|---|
| ModeSegment 選択 | 価格OCR | **商品写真** |
| reticle 形状 | 184×108（横長） | **150×150（正方）/ radius 18** |
| ガイド文 | 値札・メニューの金額を枠に | **商品全体が入るように撮る** |
| カメラ縞色 | 寒色グレー `#AEB7B0` | **暖色グレー `#B7AFA6`** |
| シャッター | 「読み取る」teal `#0E9488` ＋CTAグロー | **「商品を撮る」チャコール `#36443F` ＋弱い影**（`0 2px 6px rgba(16,33,31,0.12)`） |
| 最下行 | 残予算＋手入力導線 | **補助文「金額はあとで手入力 / 価格OCRで追加できます」**（中央・11.5/500 `#939E9B`） |

## 注意（CLAUDE.md準拠）

- シャッターは**純黒・強い浮き影は不可**。チャコール `#36443F` ＋弱い影で、価格OCR（緑）より**強すぎない**印象に。
- 補助モードである一方、起動時は必ず価格OCR。ここへはセグメントタップ or 横スワイプで遷移。

## RN移植メモ（差分）

- `ShutterButton` の `mode` prop で bg/文言/影を出し分け（`'ocr'`→teal+glow / `'product'`→`#36443F`+弱影）。
- reticle は `mode` で `width/height/borderRadius` を切替（横長↔正方）。
- 撮影後は `entryType='product'` で `product-result/` の結果パネルへ集約。
