# tabirate-ui-review

このSkillは、旅レートカメラのUI修正レビューに使います。
Claude Designの理想UIとReact Native実装の差分を見ながら、UI変更が安全境界を越えていないか確認します。

## 使う場面

- Claude Designで作った理想UIをReact Nativeへ反映するとき
- 画面レイアウト、色、余白、文言、ボタン配置を調整したとき
- 下タブ、画面遷移、旅行切替付近のUIを確認するとき
- UI修正のつもりがロジック変更へ広がっていないか見たいとき

## 確認すること

- 理想UIと実装UIの差分
- 画面の主目的が保たれているか
- 重要ボタンや導線が消えていないか
- テキストが見切れていないか
- 旅行切替や履歴表示の意味が変わっていないか
- 下タブが二重化していないか
- UI修正のついでにDB、保存処理、課金、旅行切替を触っていないか

## 触ってはいけない領域

- DBスキーマ
- 保存処理
- 保存時レート
- 履歴再計算
- 課金
- `FREE_LIMITS`
- 旅行切替
- 下タブ構成の重複生成
- OCR写真と商品写真の保存フィールド

## 注意

UIレビュー中に問題を見つけても、勝手に大きく直さず、まず指摘として出します。
修正する場合は、対象ファイルと影響範囲を限定してから行います。
