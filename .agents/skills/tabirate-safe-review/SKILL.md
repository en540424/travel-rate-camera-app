# tabirate-safe-review

このSkillは、旅レートカメラ専用の安全レビューに使います。
実装を進めるSkillではなく、壊してはいけない仕様を守れているか確認するSkillです。

## 最優先ルール

1. 保存時レート固定  
   商品保存時点の為替レートを記録し、後から変えない。
2. 履歴再計算禁止  
   過去履歴を現在レートで再計算しない。
3. `FREE_LIMITS` 単一ソース  
   無料枠の上限値を1か所に集約し、二重定義しない。
4. OCR写真と商品写真の区別  
   価格読み取り用画像とメモ用の商品画像を混同しない。
5. 下タブ二重化禁止  
   画面下部タブバーを重複生成しない。
6. DB、保存処理、課金、旅行切替を不用意に触らない。

## レビュー手順

1. 変更対象ファイルを確認する。
2. 変更内容がUI、保存、DB、課金、旅行切替のどれに当たるか分類する。
3. 最優先ルールに触れていないか確認する。
4. 不明な場合は「不明」として、実装を止める提案を出す。
5. 仕様破壊の可能性と追加確認項目を出す。

## 禁止事項

- 本体コードを勝手に変更しない。
- DB、保存処理、課金、旅行切替をついでに修正しない。
- `.env`、APIキー、認証情報を触らない。
- `git push`、`git reset`、削除系操作をしない。
