# common-dev-log

作業の **あと** に使うSkill。記憶が新しいうちに、Obsidian用とNotion用のログを作る。

## このSkillがやること

- その日の作業を構造化してログにする
- 次回AIに渡す引き継ぎプロンプトを作る
- Obsidian用（リンク重視）とNotion用（貼り付け用）を用意する

## このSkillがやらないこと

- コードの変更
- 既存ログの上書き（新規ファイルとして作る）

## 命名規則

- 開発ログ：`YYYY-MM-DD_プロジェクト名_開発ログ.md`
- Notion用：`YYYY-MM-DD_プロジェクト名_Notion用.md`
- 再開メモ：`YYYY-MM-DD_プロジェクト名_再開メモ.md`

## Obsidian用フォーマット

```md
# YYYY-MM-DD プロジェクト名

## 概要

## 作業内容

## 判断

## 次回作業

## 関連リンク
- [[プロジェクト名]]
- [[AI運用ルール]]

## タグ
#開発ログ #AI運用
```

## 開発ログ（詳細版）フォーマット

```md
# YYYY-MM-DD プロジェクト名 開発ログ

## 今日やったこと
## 発生した問題
## 原因・仮説
## 実施した修正
## 現在の状態
## 次回やること
## 次回AIに渡す指示
## 関連ファイル・関連メモ
```

## Notion用フォーマット

```md
# YYYY-MM-DD 作業ログ

## 概要
## 作業内容
## 決定事項
## 問題点
## 次回作業
## 引き継ぎプロンプト
```

## 手順

1. 今日の作業内容を聞き取り、または差分・履歴から要約する
2. 問題・原因・修正・現状を分けて整理する
3. 次回やること、引き継ぎプロンプトを作る
4. 上記フォーマットでファイルを生成する（日付は今日の日付）
5. ObsidianとNotionで内容を混同しない
